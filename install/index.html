Volcano Hybrid Companion

M5Stack Dial firmware — installed from your browser, no toolchain required.

This installs the firmware documented in firmware/README.md onto an M5Stack Dial — a local, standalone remote for the Storz & Bickel Volcano Hybrid, with an optional Home Assistant integration. It does not target the ESP32-S3 development board used earlier in this project's own development; that one is still built from source, per examples/README.md.

Chrome or Edge on a desktop only. This page uses Web Serial, a browser feature Firefox, Safari and every mobile browser lack. On one of those, build and flash from source instead — see firmware/README.md.

Your browser doesn't support Web Serial. Use Chrome or Edge on a desktop, or flash from source instead — see firmware/README.md. Web Serial needs this page over HTTPS. If you're seeing this on the real install page rather than a local copy, please open an issue.

After it installs

  1. The same button offers to configure WiFi next, over the same USB connection — enter the network it should join. Nothing further reads a WiFi password from anywhere else.
  2. The Dial finds your Volcano itself: it scans, and either pairs automatically or lets you choose if it finds more than one, right on its own screen. No address to look up or type in.
  3. To add it to Home Assistant, go to Settings → Devices & Services → Add Integration → ESPHome and enter the Dial's IP or volcano-hybrid-dial.local. With no key set yet, Home Assistant agrees one with the device itself — nothing to type in. Full detail, including what to do if that window has closed, is in firmware/README.md.

None of this is required to use the Dial: it runs its full local UI, and controls the Volcano over Bluetooth, before any of the above is done. WiFi and Home Assistant are optional.

Updating later

Once installed, later updates can be pushed over the network instead of needing this page again — see "Flashing and watching logs" in firmware/README.md.
