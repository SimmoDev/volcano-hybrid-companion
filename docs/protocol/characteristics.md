# Characteristics

**Status: no findings recorded yet.** BLE discovery has not started.

This file will record findings about individual BLE characteristics within the Volcano Hybrid's GATT services — for example, a characteristic's properties (read/write/notify) and what its value appears to represent. Each finding follows the standard format from [ADR-0006](../decisions/ADR-0006-protocol-documentation-structure.md) and is classified Confirmed, Probable, or Unknown per [ADR-0005](../decisions/ADR-0005-volcano-ble-discovery-methodology.md).

Finding IDs in this file use the `CHAR-NNN` prefix (see [`docs/CONVENTIONS.md`](../CONVENTIONS.md)).
