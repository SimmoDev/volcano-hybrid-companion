This directory holds raw, unmodified BLE evidence — sniffer logs, GATT dumps, characteristic value snapshots, and similar — that findings in [`gatt-services.md`](../gatt-services.md), [`characteristics.md`](../characteristics.md), [`commands.md`](../commands.md), and [`state-model.md`](../state-model.md) cite as their evidence, per [ADR-0006](../../decisions/ADR-0006-protocol-documentation-structure.md). Captures are never edited to fit a conclusion, and are never rewritten or discarded even if a finding based on them is later revised.

Capture files use the `YYYY-MM-DD-<short-description>.<ext>` naming format defined in [`docs/CONVENTIONS.md`](../../CONVENTIONS.md).
