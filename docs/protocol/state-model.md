**Status: no findings recorded yet.** BLE discovery has not started.

This file will record findings about how the Volcano Hybrid's device state (e.g. current/target temperature, heater state, valve state) is observed and reported over BLE. Each finding follows the standard format from [ADR-0006](../decisions/ADR-0006-protocol-documentation-structure.md) and is classified Confirmed, Probable, or Unknown per [ADR-0005](../decisions/ADR-0005-volcano-ble-discovery-methodology.md).

Finding IDs in this file use the `STATE-NNN` prefix (see [`docs/CONVENTIONS.md`](../CONVENTIONS.md)).
