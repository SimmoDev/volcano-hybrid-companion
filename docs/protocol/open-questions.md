# Open questions

**Status: empty.** BLE discovery has not started, so no open questions have been recorded yet.

This file tracks anything classified **Unknown** per [ADR-0005](../decisions/ADR-0005-volcano-ble-discovery-methodology.md), plus any open question raised during investigation that doesn't yet belong in [`gatt-services.md`](gatt-services.md), [`characteristics.md`](characteristics.md), [`commands.md`](commands.md), or [`state-model.md`](state-model.md). Per [ADR-0006](../decisions/ADR-0006-protocol-documentation-structure.md), each entry should name the question, what's already been tried or observed (if anything), and what would resolve it. An entry is removed once it's been investigated to at least Probable confidence and turned into a proper finding in the relevant file.

See [`docs/protocol/README.md`](README.md) for how this directory as a whole works.
