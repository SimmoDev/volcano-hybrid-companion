# Commands

**Status: no findings recorded yet.** BLE discovery has not started.

This file will record findings about writes/commands sent to the Volcano Hybrid and their observed effects — for example, what a particular write appears to cause the device to do. Each finding follows the standard format from [ADR-0006](../decisions/ADR-0006-protocol-documentation-structure.md) and is classified Confirmed, Probable, or Unknown per [ADR-0005](../decisions/ADR-0005-volcano-ble-discovery-methodology.md).

Finding IDs in this file use the `CMD-NNN` prefix (see [`docs/CONVENTIONS.md`](../CONVENTIONS.md)).

See [`docs/protocol/README.md`](README.md) for how this directory as a whole works.
